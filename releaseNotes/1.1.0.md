This version contains a bug fix around call logging:

- In rare circumstances, a user was not properly attached to a call log entry as the owner, leading to an error upon call completion.
- The user will now be attached as the owner for call logs in all scenarios.

Updated contact disambiguation:

- If a phone number matches multiple contacts, a prompt will ask to confirm if the log should be associated with all matching contacts, or only specific ones.
- The user is able to skip call log association with a contact and just log the call itself
